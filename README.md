# Portal E-commerce Montana

Projeto de teste da Montana Química S.A.: portal de e-commerce (fase inicial).

> **Aviso:** todos os dados deste repositório são **fictícios**. Não há credenciais, dados pessoais reais nem informações comerciais ou internas. O repositório é público apenas porque é um projeto de teste.

## Objetivo
Estabelecer a base técnica do portal: repositório, publicação via GitHub Pages e uma página inicial com a identidade visual Montana. Funcionalidades de catálogo, carrinho e pedidos virão em cards futuros.

## Estado atual
- Página inicial estática, responsiva e acessível (`index.html`).
- Estilos com a paleta Montana em `css/style.css`: #000E3B, #004995 e #AEAFB2, fonte Trebuchet MS (fallback sans-serif).
- Logo oficial (`assets/brand/montana-logo-original.png`): **pendente**. Ainda não está no repositório; a página funciona sem ela.

## Como executar
Não há build nem dependências. Abra `index.html` no navegador ou use o GitHub Pages: https://montanaquimica.github.io/portal-ecommerce/

Para servir localmente: `python3 -m http.server 8000` e acesse http://localhost:8000.

## Estrutura
```
index.html
css/style.css
assets/brand/   (logo oficial, pendente)
```
